# Mercor Project Frost: Data Science Recordings

Prep kit for two narrated screen recordings (Data Science & ML domain):

| | Use case | Recording folder |
|---|---|---|
| **UC1** | Build and explain a cross-sell / up-sell model | `recording_workspace/UC1_Cross_Sell` |
| **UC2** | Build and explain a propensity-to-pay model | `recording_workspace/UC2_Propensity_To_Pay` |

All input data is generated by the scripts in `prep/`.

> **Recording?** Follow [UC1_RECORDING_SCRIPT.md](UC1_RECORDING_SCRIPT.md) or [UC2_RECORDING_SCRIPT.md](UC2_RECORDING_SCRIPT.md): each is the only file you need during setup, rehearsal and the take.
>
> **Practising on Windows first?** Follow [WINDOWS_SETUP.md](WINDOWS_SETUP.md) to set up, rehearse and record an internal-review version on a Windows laptop. Then come back here for the final Mac recording.

## 1. Get the project onto the Mac

Repo: <https://github.com/UllasKc/LLM_Training_recording> (public: contains no confidential material; `Project_Docs/` with the confidential client guidelines is git-ignored and never pushed).

**Keep your personal GitHub login off the recording user** (Frost forbids personal accounts there). The repo is public, so no sign-in is needed. Use either option, in the macOS Terminal app, off camera:

- **Option A: git clone (no login needed)**
  ```bash
  cd ~
  git clone https://github.com/UllasKc/LLM_Training_recording.git
  ```
  If macOS asks to install "command line developer tools", click Install (or install Xcode 26 first; it includes git). To pick up later changes: `cd ~/LLM_Training_recording && git pull`
- **Option B: no git at all.** In a browser, **without signing in**, open the repo page → green **Code** button → **Download ZIP**. Then:
  ```bash
  cd ~ && unzip ~/Downloads/LLM_Training_recording-main.zip && mv LLM_Training_recording-main LLM_Training_recording
  ```

Either way the project ends up at `~/LLM_Training_recording`. Git is never opened during recording.

## 2. One-time Mac setup

1. Install **Python 3.12** from <https://www.python.org/downloads/macos/> (latest 3.12.x, "macOS 64-bit universal2 installer"). The `python3` that ships with Xcode is 3.9 and is not used.
2. In the macOS Terminal app (off camera):
   ```bash
   cd ~/LLM_Training_recording
   bash setup_mac.sh
   ```
   This creates `.venv`, installs the locked packages (prebuilt arm64 wheels only: no compiler, Homebrew or libomp needed), registers the Jupyter kernel **`Python 3.12 (ds-venv)`**, and runs `prep/verify_setup.py`. It should end with **READY**. It is safe to re-run.
3. VS Code: install the **Python** and **Jupyter** extensions (publisher: Microsoft). Do **not** install GitHub Copilot or any AI extension. In Settings, search "disable AI features" and tick it.
4. Complete section A of [use_cases/Recording_Checklist.md](use_cases/Recording_Checklist.md) (TaskRecorder, Accessibility Inspector, OTA sign-in, clock seconds, and so on).

## 3. Before each take (and to reset after a rehearsal)

```bash
bash prep/stage_recording.sh UC1     # or UC2
```

This copies a clean workspace to `~/Desktop/UC1_Cross_Sell`. A previous copy, such as a rehearsal, is **moved** to `~/Rehearsal_Backups/`, never deleted. The script also:
- removes macOS "downloaded from the internet" quarantine pop-ups from the files
- writes hidden VS Code workspace settings: AI features off, the venv interpreter, larger fonts for legibility

In VS Code: **File → Open Folder… → Desktop → UC1_Cross_Sell**. In a new notebook, choose the kernel **Python 3.12 (ds-venv)** (top right → Select Kernel → Jupyter Kernel).

## 4. After the take

Zip `~/Desktop/<UC>/Deliverables` → `Deliverables.zip`. Upload `video.mp4`, the unmodified `recording_TIMESTAMP.zip`, `Deliverables.zip` and `Metadata.rtf` to Mercor Studio, then run both AutoQC checks.

> If Mercor provides its own Metadata template, copy the three sections (App Topology, Request, Task Description) from the prepared `Metadata.rtf` into it.

## 5. Regenerating the data (optional)

The inputs are already committed. Generation is deterministic (fixed seeds), so re-running gives identical files:

```bash
.venv/bin/python prep/generate_uc1_cross_sell.py
.venv/bin/python prep/generate_uc2_propensity_to_pay.py
.venv/bin/python prep/generate_briefs.py
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| `Python 3.12 not found` | Install from python.org (step 2.1), open a new Terminal window, re-run `bash setup_mac.sh` |
| `permission denied: ./setup_mac.sh` | Run it as `bash setup_mac.sh` (no execute bit needed) |
| Kernel `Python 3.12 (ds-venv)` not listed in VS Code | Reload the VS Code window (View → Command Palette → "Developer: Reload Window"), or re-run `bash setup_mac.sh` |
| VS Code asks to install `ipykernel` | You picked the wrong interpreter; select the `ds-venv` kernel instead |
| "File downloaded from the internet" pop-up | Re-run `bash prep/stage_recording.sh UC1` (it clears the quarantine flag) |
| Excel opens the CSV with the wrong delimiter or encoding | Open it via File → Open (it's comma-separated UTF-8) |
| pip errors behind a corporate proxy or VPN | Frost forbids VPN/proxy at sign-in anyway. Disconnect and re-run setup |
